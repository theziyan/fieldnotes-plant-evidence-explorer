# Fieldnotes — Plant Evidence Explorer

A small hackathon prototype for exploring medicinal plant evidence while keeping source type, attribution, and uncertainty visible.

## Run it

Open `index.html` in a modern browser. There is no build step or server dependency.

## Prototype behavior

- Search records by plant, topic, reported use, or source
- Filter by plant and evidence type
- Open the linked references
- See limitations and evidence context on every record

## Data and limitations

The current records are a curated UI demonstration, not a comprehensive or validated dataset. They link to source material for verification. The Kew Useful Plants database is linked as a discovery source; the current demo does **not** reproduce database records or claim a specific entry without verification. Review article links are provided for context and should be checked before any public judging submission. Add exact quotations or structured data only after confirming source content, licences, attribution rules, and cultural context. Do not use this prototype to make diagnosis or treatment decisions.
